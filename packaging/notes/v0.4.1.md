Fixes to the page's column and to Markdown that carries metadata.

**The column keeps its measure.** An image with a long description, or a word longer than the line — a URL, a key fingerprint, a line of JSON in a code block — could push the text wider than its measure, on some pages to the edge of the window, or slide it sideways so that the starts of lines were cut off. Captions now wrap within the column, and a word too long for the line breaks inside it.

**Front matter stays out of the text.** Markdown that opens with YAML front matter — the Markdown copy some sites serve, a Jekyll or Hugo page in a repository — no longer shows the metadata as one huge heading; the page's title is taken from it when the text has none.

Files: `brevier.flatpak` (any distribution, with Flatpak), `brevier-0.4.1-x86_64-linux.tar.gz` (GTK 4 from the system), `brevier-0.4.1-arm64.apk` (Android 7 and later, 64-bit ARM, signed with the release key — it installs over earlier versions), and `SHA256SUMS`.
