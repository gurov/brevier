Feeds, the rest of the way: JSON Feed, `feed://` links, feed files, and threads.

**JSON Feed.** A JSON feed — served as `application/feed+json` or as plain `application/json` — opens as a list of links, like RSS and Atom.

**`feed://` links and feed files.** The old "subscribe" links (`feed://host/path`, `feed:https://…`) open the feed they name: from the address bar, the command line, or a link another program hands over — Brevier now registers for them on Linux and Android. A feed saved to disk opens from its path, on Android too: from Downloads or a file manager, which also opens Markdown files there.

**Threads.** A feed that discusses one page reads as a thread: a reddit thread, or the comments on a WordPress post. The post comes in full, then every comment with its author and date, in full — flat, because a feed does not say who answers whom, and the page says so. reddit's own pages are empty without JavaScript, so a reddit thread or subreddit address is read through its feed. reddit allows few requests in a row without an account; when it asks to slow down, Brevier says so.

Files: `brevier.flatpak` (any distribution, with Flatpak), `brevier-0.4.0-x86_64-linux.tar.gz` (GTK 4 from the system), `brevier-0.4.0-arm64.apk` (Android 7 and later, 64-bit ARM, signed with the release key — it installs over earlier versions), and `SHA256SUMS`.
