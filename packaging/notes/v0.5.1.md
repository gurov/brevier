Fixes on the phone, for two book sites, and for code in lists and quotes.

**Open in your browser on the phone.** With Brevier as the default browser, the button on a page that did not open — and the same item in the menu — said "No apps can perform this action" and opened nothing. When there is more than one other browser, Brevier now asks which one itself; a single other browser opens straight away. The button is also no longer drawn twice, and closing find on page no longer leaves the previous tab's address in the address bar.

**A link from another app.** A tab opened by a link from another app — a news feed, a chat — starts at that page: Back is greyed out on it, and on the phone the back gesture returns to the app the link came from. On a tab you opened yourself, Back on the first page still leads to the start page.

**Books on royallib.** The reader there loads all but the first part of a book by script, so Brevier read only the beginning. Each part now opens as a page of its own, with links to the previous and the next part under the text. The paragraph indent that book sites type with spaces is gone too: paragraphs are set by Brevier's typography, not the site's.

**A script instead of the page.** A site that answers with a script that sets a cookie and reloads the page used to get "There is no article on this page". Brevier now says the site lets in only browsers that run JavaScript, and offers to open the page in your browser.

**Code in lists and quotes.** A code block inside a list item or a quote stands under the item's or the quote's text instead of at the edge of the column, and the quote's rule no longer breaks off around it.

Files: `brevier.flatpak` (any distribution, with Flatpak), `brevier-0.5.1-x86_64-linux.tar.gz` (GTK 4 from the system), `brevier-0.5.1-arm64.apk` (Android 7 and later, 64-bit ARM, signed with the release key — it installs over earlier versions), and `SHA256SUMS`.
