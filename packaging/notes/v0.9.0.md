The type is yours, and a few fixes.

**Your type, chosen once for every site.** Settings have a new Type section, in the window and on the phone. Choose the face — the built-in Noto Sans, or whatever your system calls serif or sans — the size, the line length and the line spacing. A sample above the choices is set in what you pick, and every page follows. The size scales the whole page, headings, indents and code panels included, and the line length is kept in ems, so a line holds the same number of letters at any size. Zoom stays what it was: on top of your type, for the run only. Only what you change is written to `settings.tsv`.

**Justified text**, as a setting. Paragraphs get a straight right edge; headings, lists, code and poems stay ragged. It reads best on pages that name their language, because Brevier hyphenates only those.

**More pages are hyphenated.** A page with no language on `<html>` but with one on its `<body>`, `<main>` or `<article>` is now hyphenated by it.

**Archive search shows the text you read.** A snippet used to show the Markdown behind it — a link's `](address)`, backquotes, asterisks. It now shows plain text, and a word that appears only in a link's address no longer counts as a match.

**On the phone, a link from another app opens on top.** If the tab list, settings or the shelf was open when you left Brevier, a link you then shared or tapped in another app opened under it. Now the page comes first.

Files: `brevier.flatpak` (any distribution, with Flatpak), `brevier-0.9.0-x86_64-linux.tar.gz` (GTK 4 from the system), `brevier-0.9.0-arm64.apk` (Android 7 and later, 64-bit ARM, signed with the release key — it installs over earlier versions), `brevier-0.9.0-windows-x86_64-setup.exe` and `brevier-0.9.0-windows-x86_64.zip` (Windows 10 and 11, 64-bit), and `SHA256SUMS`.
