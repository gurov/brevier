A fix for code blocks in the window. Nothing changes on the phone.

**Code blocks in the window.** A code block is drawn as one panel: the margin above and below the code and any empty line inside it are painted like the lines of code. They used to keep the colour of the page, so the panel was a thin strip under the code, cut in two at every empty line. On the phone the panel was already whole.

**Extraction.** The fix that keeps Wikipedia's photographs from turning into their description pages now lives in the extraction library itself (dom_smoothie 0.18.2, from a patch sent upstream), and Brevier's own workaround is gone. Pages read exactly as before.

Files: `brevier.flatpak` (any distribution, with Flatpak), `brevier-0.5.5-x86_64-linux.tar.gz` (GTK 4 from the system), `brevier-0.5.5-arm64.apk` (Android 7 and later, 64-bit ARM, signed with the release key — it installs over earlier versions), and `SHA256SUMS`.
