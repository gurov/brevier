Security fixes. Updating is recommended on every platform.

**A picture inside an SVG no longer reaches your disk.** An SVG image on a web page could put a file from your computer into the picture, or make Brevier read until memory ran out; on Windows it could name a network share, and Windows would send that share your password hash as soon as the page opened. An SVG now shows only the pictures it carries inside itself.

**A deeply nested page no longer crashes Brevier.** A page, feed, SVG or Markdown file with markup nested hundreds or thousands of levels deep could crash the program with all its tabs, or keep a tab busy for minutes. Such pages are now refused with "The page is nested too deeply"; real pages come nowhere near the limit. `--check` reports them as `access-too-deep`.

**TLS.** rustls 0.23.45 fixes a flaw in the TLS 1.3 handshake (RUSTSEC-2026-0285).

**Smaller.** On Windows an archive address can no longer name a file outside the archive, and the release build pins the third-party steps that make its files.

Files: `brevier.flatpak` (any distribution, with Flatpak), `brevier-0.8.1-x86_64-linux.tar.gz` (GTK 4 from the system), `brevier-0.8.1-arm64.apk` (Android 7 and later, 64-bit ARM, signed with the release key — it installs over earlier versions), `brevier-0.8.1-windows-x86_64-setup.exe` and `brevier-0.8.1-windows-x86_64.zip` (Windows 10 and 11, 64-bit), and `SHA256SUMS`.
