Brevier on Windows, and a margin in a narrow window.

**Windows.** The window now runs on Windows 10 and 11, 64-bit. `brevier-0.8.0-windows-x86_64-setup.exe` installs it for you alone, with no administrator rights: it adds Brevier to the Start menu and offers it as a browser and under "Open with" for Markdown and feeds. Remove it under Installed apps; your history and bookmarks in `%LOCALAPPDATA%\Brevier` stay. `brevier-0.8.0-windows-x86_64.zip` is the same program to run from any folder. The command line comes along as `bin\brevier.exe`. The installer is not signed yet, so the first start shows "Windows protected your PC": choose More info, then Run anyway. Screen readers do not see the window on Windows yet.

**A margin in a narrow window.** The text no longer touches the frame when the window is narrow: it keeps a margin of one text size on each side, as on the phone.

**Your disk stays yours.** A link on a web page to a file on your computer — `file://`, `C:\…`, a network share — no longer opens it, and an image on a web page can't be read from your disk, as in other browsers.

**A Markdown file with a space in its name**, handed over by a file manager as a `file://` address, opens: the space used to stay `%20` in the path.

Files: `brevier.flatpak` (any distribution, with Flatpak), `brevier-0.8.0-x86_64-linux.tar.gz` (GTK 4 from the system), `brevier-0.8.0-arm64.apk` (Android 7 and later, 64-bit ARM, signed with the release key — it installs over earlier versions), `brevier-0.8.0-windows-x86_64-setup.exe` and `brevier-0.8.0-windows-x86_64.zip` (Windows 10 and 11, 64-bit), and `SHA256SUMS`.
