A reproducible Android build. Nothing changes in the app itself.

**Android.** The APK is now built reproducibly: from the same source, with the same pinned Rust, NDK and JDK, it comes out the same byte for byte wherever it is built. That is what F-Droid needs in order to publish Brevier with our signature instead of its own, so that an install from F-Droid and one from these releases can update each other. The certificate check now comes from source rather than from a prebuilt component; HTTPS and the revocation check behave as before.

**Linux.** No changes.

Files: `brevier.flatpak` (any distribution, with Flatpak), `brevier-0.5.3-x86_64-linux.tar.gz` (GTK 4 from the system), `brevier-0.5.3-arm64.apk` (Android 7 and later, 64-bit ARM, signed with the release key — it installs over earlier versions), and `SHA256SUMS`.
