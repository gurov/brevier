A smaller APK. Nothing changes in the app itself.

**Android.** Unused code is now stripped from the APK (R8, as the F-Droid review asked): the app's own code goes from 2.2 MB to 144 KB, and the APK from 13.7 MB to 13.0 MB. Most of what is left is the reading core, which was already as small as its compiler makes it. The build is still reproducible.

**Linux.** No changes.

Files: `brevier.flatpak` (any distribution, with Flatpak), `brevier-0.5.4-x86_64-linux.tar.gz` (GTK 4 from the system), `brevier-0.5.4-arm64.apk` (Android 7 and later, 64-bit ARM, signed with the release key — it installs over earlier versions), and `SHA256SUMS`.
